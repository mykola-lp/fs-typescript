This is a [TypeScript](https://www.typescriptlang.org/) project.

## Getting started

**Clone the entire repository:**

```bash
git clone <repository-url>
cd <repository-directory>
````

Each project has its own dependencies and should be run from its respective directory.

For **projects that contain separate frontend and backend** applications, navigate to the required directory first:

```bash
cd <project>/<frontend-or-backend>
```

## Project structure

The repository contains multiple independent course projects. Each project that was worked on includes a `README.md` with a description of the task and instructions for running it.

Some projects are included as provided by the course.
